# 延河课堂 DDL 监控 · yanhektddl-mon

作业/测验截止日期 **一键查看 · 一键直达 · 每日自动提醒**。

自动读取延河课堂(aita.yanhekt.cn)与北理工乐学 eclass 上你自己的课程数据,
汇总成一张按截止时间排序的清单:临期任务高亮、漏交任务报警、点一下直达作业页面。

> **隐私:登录会话、课程和作业数据只保存在本机程序目录,不上传任何服务器。**
> 程序在浏览器会话内调用平台官方接口,仅读取使用者本人的课程信息,
> 不抓取、不存储任何同学的数据。

本文件同时是**使用手册**和**开发指引**。

---

## 功能

- **零依赖**:单个 exe,双击即用,无需安装 Python 或任何环境(用系统自带的 Edge)
- **一屏总览**:所有课程的作业、测验、问卷按截止时间排序,倒计时按秒跳动
- **临期高亮**:红 = 已过期未提交 / 橙 = 3 天内 / 黄 = 7 天内 / 灰 = 已完成
- **一键直达**:点击任务行或「打开 ↗」直接进入平台对应页面
- **作业详情**:展开老师填写的作业要求原文
- **后台刷新**:点「刷新数据」在后台重新抓取,不阻塞窗口
- **每日巡检**:可选每天早上 9:00 自动检查,临期/漏交弹出 Windows 通知
- **系统托盘**:关掉窗口后服务仍在托盘运行,右键「打开窗口 / 退出」,高分屏下菜单清晰(DPI 感知)
- **报告输出**:同时生成 `ddl_report.md` / `ddl_report.csv` 报告文件
- **干净卸载**:一键删除桌面图标、计划任务、运行中的服务和程序目录

## 环境要求

| 需要 | 说明 |
|---|---|
| Windows 10 / 11 | 64 位 |
| Microsoft Edge | 系统自带,无需额外安装(缺 Edge 时自动尝试 Chrome) |
| 能访问校园平台 | 校园网 / VPN 环境下使用 |

## 快速开始(使用者)

**方式一:安装包(推荐)**

运行 `yanhektddl-setup-<版本>.exe`,一路下一步:

- 免管理员、免 UAC,安装到 `%LOCALAPPDATA%\Programs\YanhektDDL`(Chrome 同款目录)
- 自动创建开始菜单/桌面图标,可勾选「每天 9:00 自动巡检提醒」
- 在「设置 → 应用」里一键卸载:自动停服务(含残留的抓取浏览器)、删计划任务、
  删图标;卸载时可选择保留或删除登录数据

**方式二:便携版**

1. 把程序文件夹解压/放到任意位置(建议非系统盘)
2. 双击 **`yanhektddl.exe`** → 首次运行自动弹出 Edge 窗口,
   登录一次延河课堂(账号 + 密码 + 图形验证码,只需这一次)
3. 登录完成后自动抓取并打开「延河课堂DDL」速查窗口

建议再做两件事(均可选):

- 运行 **`创建桌面快捷方式.bat`**,以后双击桌面图标即可打开速查窗口
- 命令行运行一次 `yanhektddl.exe --install-task`,开启每天 9:00 自动巡检提醒
  (对应卸载:`--uninstall-task`)

## 日常使用

| 操作 | 效果 |
|---|---|
| 双击 `yanhektddl.exe` / 桌面「延河课堂DDL」 | 打开速查窗口(服务已在跑则秒开) |
| 点任意任务行 / 「打开 ↗」 | 直达该作业/测验页面 |
| 点「详情」 | 展开老师写的作业要求原文 |
| 点「刷新数据」 | 后台重新抓取(约 1-2 分钟) |
| 每天早上 9:00(如已开启) | 自动巡检,临期/漏交弹 Windows 通知 |
| **关闭速查窗口** | 服务继续在系统托盘运行;右键托盘图标可「打开窗口」或「退出」 |
| **托盘左键单击 / 右键→打开窗口** | 重新打开速查窗口(服务已在跑则秒开) |
| **托盘右键→退出** | 停止后台服务并退出(彻底关闭的推荐方式) |

窗口里的颜色:红 = 已过期未提交 / 橙 = 3 天内 / 黄 = 7 天内 / 灰 = 已完成;
右栏是每门课的开放截止时间。倒计时按秒实时跳动。

## 命令行参数(高级)

| 参数 | 说明 |
|---|---|
| (无参数) | 桌面模式:启动本地服务 + 打开速查窗口 |
| `--fetch` | 单次抓取并生成报告(可配合下列参数) |
| `--days N` | 「临期」阈值天数,默认 3 |
| `--watch N` | 每 N 分钟自动巡检一次(可 `Ctrl+C` 停止) |
| `--notify` | 发现临期/漏交任务时弹出 Windows 通知 |
| `--visible` | 显示浏览器窗口,便于排查登录/抓取问题 |
| `--from-json [路径]` | 不联网,直接用 `ddl_data.json`(或指定快照)生成报告 |
| `--install-task` | 注册每天 9:00 的计划任务(内部以 `--fetch --days 3 --notify` 巡检) |
| `--uninstall-task` | 删除该计划任务 |
| `--quit` | 通知运行中的桌面服务退出(脚本/排障用) |

## 常见问题

**Q:提示需要登录?**
登录会话长期有效;只有学校强制过期时才需要重新登录 —— 程序会自动弹出 Edge,
输入一次账号密码和图形验证码即可,其余全自动。

**Q:抓取失败?**
确认能在浏览器手动登录延河课堂;确认校园网/VPN 已连;然后点「刷新数据」重试。

**Q:数据存在哪?在本机怎么删?**
全部在程序目录:`browser_profile\`(登录会话)、`ddl_data.json`(数据)、
`ddl_report.md/.csv`(报告)。删除文件夹即彻底清除。

**Q:想改巡检时间/频率?**
```powershell
yanhektddl.exe --watch 60 --notify   # 每 60 分钟巡检一次
yanhektddl.exe --days 7              # "临期"阈值改为 7 天
```

**Q:双击后窗口一闪而过?**
服务在后台运行并常驻系统托盘,速查窗口由 Edge 应用窗口承载。
若 Edge 窗口没弹出,点托盘图标的「打开窗口」,或查看程序目录下 `server.log` 排错。

**Q:程序怎么彻底关闭?**
**右键系统托盘里的本程序图标 → 退出**。关掉速查窗口只是关了窗口,
服务仍在托盘运行(这样下次点托盘就能秒开)。
命令行也可以:`yanhektddl.exe --quit`。

**Q:Windows Defender 提示病毒?**
旧版依赖库会在 `%TEMP%` 释放监视程序(易被误判);当前版本已彻底移除该行为,
不在任何临时目录释放可执行文件,抓取用你系统自带的 Edge。如果之前拦截过一次,
在"病毒和威胁防护 → 保护历史记录"里移除即可;若 exe 本体被隔离,
对其添加排除项后重新下载/构建。

长期分发的根治方案是**代码签名**:无签名的新 exe 总有机会触发
Defender/SmartScreen 启发式(与是否用安装包无关);Azure Trusted Signing
已对个人开发者开放(约 $9.99/月),签名后误报问题基本消失。

## 卸载

**安装版**:「设置 → 应用 → 延河课堂 DDL」卸载,或运行安装目录里的
`unins000.exe`。自动停服务(包括强杀后遗留的抓取浏览器 Edge 进程,否则
会占住 `browser_profile` 文件锁)、删计划任务、删图标;随后弹窗询问
「是否保留用户数据」——选「是」保留登录会话与报告(推荐,便于重装免登录),
选「否」一并清除,不留任何残留。静默卸载(`/VERYSILENT`)默认保留数据。

**便携版**:双击程序文件夹里的 **`卸载.bat`**,按提示输入 `y` 回车即可 →
自动删除桌面图标、巡检任务、运行中的服务和整个文件夹。

手动卸载(等价操作):

1. 删除桌面「延河课堂DDL」快捷方式
2. 命令行运行 `yanhektddl.exe --uninstall-task`(或 PowerShell:
   `Unregister-ScheduledTask -TaskName 'YanhektDDLMonitor'`)
3. 删除整个程序文件夹

程序运行后会在同目录生成以下文件(均已加入 `.gitignore`,不要提交):

| 文件/目录 | 内容 |
|---|---|
| `browser_profile/` | 持久化浏览器会话(含登录 Cookie,**属于隐私数据**) |
| `ddl_data.json` | 抓取数据快照(课程、任务、提交状态) |
| `ddl_report.md` / `ddl_report.csv` | 生成的截止日期报告 |
| `server.log` | 桌面模式运行日志 |

## 工作原理

1. **抓取**:exe 通过 CDP(rod 库)启动一个独立的持久化 Edge 会话,
   会话保存在 `browser_profile/`,不影响日常使用的浏览器。
2. 在已登录的会话内调用平台官方接口:
   - 延河课堂课程列表 → 课程 `zhiyuan_id` 与课程关闭时间
   - eclass 作业 / 考试 / 问卷接口 → 任务与截止时间
   - 提交状态接口 → 是否已完成
3. 数据写入 `ddl_data.json`,统一计算剩余时间、分组和报告,
   同时供 Markdown/CSV 报告与本地页面使用。
4. **桌面模式**:在 `127.0.0.1:8765` 提供页面与 `/api/refresh` 后台刷新接口,
   并以 Edge 应用窗口(`--app`)打开速查页;重复启动时只新开窗口,不会起第二个服务。
   窗口通过 SSE 长连接(`/api/live`)向服务报存活:**所有窗口关闭后服务自动退出**,
   `--quit`/`/api/quit` 可随时优雅关闭,程序不会在后台无痕残留。

## 开发与调试

```powershell
# 构建(产出单文件 yanhektddl.exe,需本机已装 Go)
go build -trimpath -ldflags "-s -w" -o yanhektddl.exe .

# 直接抓取一次,生成 ddl_report.md / ddl_report.csv
./yanhektddl.exe --fetch

# 需要观察浏览器行为时(显示 Edge 窗口)
./yanhektddl.exe --fetch --visible

# 直接用已有快照重新生成报告,不打开浏览器
./yanhektddl.exe --from-json

# 桌面模式:本地服务 + 速查页面
./yanhektddl.exe   # 同“无参数”

# 浏览器连通性冒烟测试(真实 headless Edge 起停,无需登录)
go test -run TestBrowserSmoke -v .

# 构建 Windows 安装包(需 Inno Setup,缺失时自动经 winget 安装)
./build-installer.ps1            # 产出 dist/yanhektddl-setup-<版本>.exe
./build-installer.ps1 -Version 0.3.1
```

开发期也可以 `go run .` 代替构建(数据目录会自动落到工作目录)。
