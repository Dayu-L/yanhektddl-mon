# 延河课堂 DDL 监控 · yanhektddl-mon

作业/测验截止日期 **一键查看 · 一键直达 · 每日自动提醒**。

自动读取延河课堂(aita.yanhekt.cn)、北理工乐学 eclass 与智慧树在线学堂(共享课 + 智慧课程)
上你自己的课程数据,汇总成一张按截止时间排序的清单:临期任务高亮、漏交任务报警、
点一下直达作业页面。

> **隐私:登录会话、课程和作业数据只保存在本机程序目录,不上传任何服务器。**
> 程序在浏览器会话内调用平台官方接口,仅读取使用者本人的课程信息,
> 不抓取、不存储任何同学的数据。

本文件同时是**使用手册**和**开发指引**。

---

## 功能

- **零依赖**:单个 exe,双击即用,无需安装 Python 或任何环境(用系统自带的 Edge)
- **多平台汇总**:延河课堂 / 乐学 eclass 的作业与测验、智慧树共享课与智慧课程的作业测试 / 考试 / 话题讨论,同一张清单呈现;速查页按数据源打标签,可一键只看某一个平台
- **一屏总览**:所有课程的作业、测验、问卷按截止时间排序,倒计时按秒跳动
- **临期高亮**:红 = 已过期未提交 / 橙 = 3 天内 / 黄 = 7 天内 / 灰 = 已完成
- **一键直达**:点击任务行或「打开」图标直接进入平台对应页面
- **忽略 DDL**:对无关紧要的任务点「忽略」,不再出现在临期列表、报告与通知中,可在右栏「已忽略」随时恢复
- **作业详情**:展开老师填写的作业要求原文
- **后台刷新**:点「刷新数据」在后台重新抓取,不阻塞窗口
- **每日巡检**:可选每天早上 9:00 自动检查,临期/漏交弹出 Windows 通知
- **设置页**:自动检测开关与时间、关闭窗口行为(退出 / 最小化到托盘)都能自己改,设置保存在本机
- **系统托盘**:关掉窗口后服务仍在托盘运行,右键「打开窗口 / 退出」,高分屏下菜单清晰(DPI 感知)
- **严格单实例**:重复双击只会把已有窗口叫出来,不会起第二个服务(Windows 命名互斥量)
- **报告输出**:同时生成 `ddl_report.md` / `ddl_report.csv` 报告文件
- **干净卸载**:一键删除桌面图标、计划任务、运行中的服务和程序目录

## 环境要求

| 需要 | 说明 |
|---|---|
| Windows 10 / 11 | 64 位 |
| Microsoft Edge | 系统自带,无需额外安装(缺 Edge 时自动尝试 Chrome;旧版 Edge 会自动回退到 WebSocket 传输) |
| 能访问校园平台 | 校园网 / VPN 环境下使用 |

**不再需要 Python。** 旧版 Python 实现(Playwright 方案)完整保留在
[`legacy_python/`](legacy_python/) 目录,仅供追溯,不再维护。

## 快速开始(使用者)

**方式一:安装包(推荐)**

运行 `yanhektddl-setup-<版本>.exe`,一路下一步:

- 免管理员、免 UAC,安装到 `%LOCALAPPDATA%\Programs\YanhektDDL`(Chrome 同款目录)
- 自动创建开始菜单/桌面图标,可勾选「每天 9:00 自动巡检提醒」
- 在「设置 → 应用」里一键卸载:自动停服务(含残留的抓取浏览器)、删计划任务、
  删图标;卸载时可选择保留或删除登录数据

**方式二:便携版**

1. 把程序文件夹解压/放到任意位置(建议非系统盘)
2. 双击 **`yanhektddl.exe`** → 首次运行自动弹出 Edge 窗口,
   登录一次延河课堂(账号 + 密码 + 图形验证码,只需这一次)
3. 登录完成后自动抓取并打开「延河课堂DDL」速查窗口

窗口里会依次给出三个步骤,**只有第 1 步是必须的**:

| 步骤 | 数据源 | 登录方式 | 跳过的影响 |
|---|---|---|---|
| 1 | 乐学 zy-eclass | 北理工统一身份认证(i北理扫码/通行密钥/短信) | 无法抓取任何作业 |
| 2 | 延河课堂(可选) | 账号 + 密码 + 验证码 | 课程关闭时间沿用上次快照 |
| 3 | 智慧树在线学堂(可选) | 微信扫码 / 手机号 | 不抓取共享课与智慧课程的作业/考试/话题讨论 |

已登录过的数据源会自动跳过提示(探测到会话就直走)。日常 `--fetch`(无
可见窗口)时如果智慧树没登录过,只会提示一句、不影响其他平台;想补上就运行一次
`--fetch --visible`,在弹窗里登录智慧树。

建议再做两件事(均可选):

- 运行 **`scripts\创建桌面快捷方式.bat`**,以后双击桌面图标即可打开速查窗口
- 命令行运行一次 `yanhektddl.exe --install-task`,开启每天 9:00 自动巡检提醒
  (对应卸载:`--uninstall-task`)

## 日常使用

| 操作 | 效果 |
|---|---|
| 双击 `yanhektddl.exe` / 桌面「延河课堂DDL」 | 只在没开窗口时新建;已开着就把它切到前台,不会开第二个 |
| 点任意任务行 / 「打开 ↗」 | 直达该作业/测验页面 |
| 点「详情」 | 展开老师写的作业要求原文 |
| 点「刷新数据」 | 后台重新抓取(约 1-2 分钟) |
| 点右上角「设置」/ 托盘右键→设置 | 开关自动检测、设置检测时间、选择关闭窗口行为 |
| 按设置的检测时间(如已开启) | 自动巡检,临期/漏交弹 Windows 通知 |
| **关闭速查窗口** | 默认最小化到托盘(服务继续运行);若在设置里选了「退出程序」,最后一个窗口关闭约 20 秒后退出 |
| **托盘左键单击 / 右键→打开窗口** | 同上:已有窗口则前置(最小化会自动还原),没有才新建 |
| **托盘右键→退出** | 停止后台服务、关闭速查窗口并退出(彻底关闭的推荐方式;不影响你日常的 Edge 窗口) |

窗口里的颜色:红 = 已过期未提交 / 橙 = 3 天内 / 黄 = 7 天内 / 灰 = 已完成;
右栏是每门课的开放截止时间。倒计时按秒实时跳动。

## 命令行参数(高级)

| 参数 | 说明 |
|---|---|
| (无参数) | 桌面模式:启动本地服务 + 打开速查窗口 |
| `--fetch` | 单次抓取并生成报告(可配合下列参数) |
| `--days N` | 「临期」阈值天数,默认 3 |
| `--watch N` | 每 N 分钟自动巡检一次(可 `Ctrl+C` 停止) |
| `--notify` | 发现临期/漏交任务时弹出 Windows 通知 |
| `--visible` | 显示浏览器窗口,便于排查登录/抓取问题 |
| `--from-json [路径]` | 不联网,直接用 `ddl_data.json`(或指定快照)生成报告 |
| `--install-task` | 注册每天 9:00 的计划任务(内部以 `--fetch --days 3 --notify` 巡检) |
| `--uninstall-task` | 删除该计划任务 |
| `--quit` | 通知运行中的桌面服务退出(脚本/排障用) |

## 常见问题

**Q:提示需要登录?**
登录会话长期有效;只有学校强制过期时才需要重新登录 —— 程序会自动弹出 Edge,
输入一次账号密码和图形验证码即可,其余全自动。桌面模式运行期间,程序还会每 10 分钟
轻量访问一次平台接口给会话“保温”,尽量避免登录窗再次弹出。

**Q:抓取失败?**
确认能在浏览器手动登录延河课堂;确认校园网/VPN 已连;然后点「刷新数据」重试。

**Q:提示 `chrome failed to start`?**
说明程序找到了 Edge/Chrome,但抓取用的浏览器实例没起来。常见原因是上一次
抓取进程没退干净占着 `browser_profile` 锁,或浏览器版本较旧。程序会自动清锁
并退避重试,较旧浏览器会自动切换到 WebSocket 传输;仍失败时:

1. 点页面上的「重试」
2. 右键系统托盘图标「退出」后重新打开程序
3. 仍不行,把程序目录下的 `server.log` 发给开发者(里面有浏览器路径与完整报错)

> 若报错时弹出的 Edge 窗口停在 `about:blank` 一动不动,属于 Edge 133+ 的
> 兼容层重启 bug(Edge 启动后自我重启一次,原进程随即退出,自动化端就此失联)。
> 程序已通过启动参数 `--edge-skip-compat-layer-relaunch` 规避;旧版安装包遇到
> 此问题请更新到最新版。

**Q:数据存在哪?在本机怎么删?**
全部在程序目录:`browser_profile\`(登录会话)、`ddl_data.json`(数据)、
`settings.json`(设置)、`ddl_report.md/.csv`(报告)。删除文件夹即彻底清除。

**Q:想改巡检时间/频率?**
打开速查页右上角「设置」(或托盘右键→设置):
- 可开关自动检测,并把每日检测时间改成任意 `HH:MM`
- 自动检测由 Windows 计划任务执行,程序没打开也会按时运行
- 想更频繁地巡检,仍可用命令行 `yanhektddl.exe --watch 60 --notify`(每 60 分钟)

**Q:双击后窗口一闪而过?**
服务在后台运行并常驻系统托盘,速查窗口由 Edge 应用窗口承载。
若 Edge 窗口没弹出,点托盘图标的「打开窗口」,或查看程序目录下 `server.log` 排错。

**Q:程序怎么彻底关闭?**
**右键系统托盘里的本程序图标 → 退出**。默认关掉速查窗口只是把它收进托盘,
服务仍在运行;如果希望关窗即彻底退出,可在「设置 → 关闭窗口时」选择
**退出程序**。命令行也可以:`yanhektddl.exe --quit`。

**Q:Windows Defender 提示病毒?**
旧版依赖库会在 `%TEMP%` 释放监视程序(易被误判);当前版本已彻底移除该行为,
不在任何临时目录释放可执行文件,抓取用你系统自带的 Edge。如果之前拦截过一次,
在"病毒和威胁防护 → 保护历史记录"里移除即可;若 exe 本体被隔离,
对其添加排除项后重新下载/构建。

长期分发的根治方案是**代码签名**:无签名的新 exe 总有机会触发
Defender/SmartScreen 启发式(与是否用安装包无关);Azure Trusted Signing
已对个人开发者开放(约 $9.99/月),签名后误报问题基本消失。

## 卸载

**安装版**:「设置 → 应用 → 延河课堂 DDL」卸载,或运行安装目录里的
`unins000.exe`。自动停服务(包括强杀后遗留的抓取浏览器 Edge 进程,否则
会占住 `browser_profile` 文件锁)、删计划任务、删图标;随后弹窗询问
「是否保留用户数据」——选「是」保留登录会话与报告(推荐,便于重装免登录),
选「否」一并清除,不留任何残留。静默卸载(`/VERYSILENT`)默认保留数据。

**便携版**:双击程序文件夹里 `scripts\卸载.bat`,按提示输入 `y` 回车即可 →
自动删除桌面图标、巡检任务、运行中的服务和整个文件夹。

手动卸载(等价操作):

1. 删除桌面「延河课堂DDL」快捷方式
2. 命令行运行 `yanhektddl.exe --uninstall-task`(或 PowerShell:
   `Unregister-ScheduledTask -TaskName 'YanhektDDLMonitor'`)
3. 删除整个程序文件夹

## 工作原理

1. **抓取**:exe 通过 CDP(chromedp 库)启动一个独立的持久化 Edge 会话,
   会话保存在 `browser_profile/`,不影响日常使用的浏览器。默认走管道传输;
   若浏览器版本较旧或被策略限制导致管道不可用,自动回退到
   `--remote-debugging-port=0` 的 WebSocket 传输(仅绑定 127.0.0.1)。
2. 在已登录的会话内调用平台官方接口:
   - 延河课堂课程列表 → 课程 `zhiyuan_id` 与课程关闭时间
   - eclass 作业 / 考试 / 问卷接口 → 任务与截止时间
   - 提交状态接口 → 是否已完成
   - 智慧树共享课的课程/作业/考试列表(Go 侧带 Cookie 直接请求,需先预热作业考试页)
   - 智慧树智慧课程列表与任务列表 → 作业测试 / 考试 / 话题讨论及其截止时间
     (该平台的参数需 `secretStr` 签名,细节见 `docs/zhihuishu-api.md`;
     该数据源属增量来源,未登录或接口异常时只记日志跳过)
3. 数据写入 `ddl_data.json`,统一计算剩余时间、分组和报告,
   同时供 Markdown/CSV 报告与本地页面使用。
4. **桌面模式**:在 `127.0.0.1:8765` 提供页面与 `/api/refresh` 后台刷新接口,
   并以 Edge 应用窗口(`--app`)打开速查页;重复启动时只新开窗口,不会起第二个服务。
   窗口通过 SSE 长连接(`/api/live`)向服务报存活:**所有窗口关闭后服务自动退出**,
   `--quit`/`/api/quit` 可随时优雅关闭,程序不会在后台无痕残留。

## 开发与调试

```powershell
# 构建(产出单文件 yanhektddl.exe,需本机已装 Go)
go build -trimpath -ldflags "-s -w" -o yanhektddl.exe .

# 直接抓取一次,生成 ddl_report.md / ddl_report.csv
./yanhektddl.exe --fetch

# 需要观察浏览器行为时(显示 Edge 窗口)
./yanhektddl.exe --fetch --visible

# 直接用已有快照重新生成报告,不打开浏览器
./yanhektddl.exe --from-json

# 桌面模式:本地服务 + 速查页面
./yanhektddl.exe   # 同“无参数”

# 浏览器连通性冒烟测试(真实 headless Edge 起停,无需登录)
go test -run TestBrowserSmoke -v .

# 构建 Windows 安装包(需 Inno Setup,缺失时自动经 winget 安装)
./installer/build-installer.ps1            # 产出 dist/yanhektddl-setup-<版本>.exe
./installer/build-installer.ps1 -Version 0.4.0
```

开发期也可以 `go run .` 代替构建(数据目录会自动落到工作目录)。
